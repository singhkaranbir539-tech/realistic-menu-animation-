# Animations / camera system
Animation is data-driven: every shot in `storyboard/shots.json` (generated by `scripts/storyboard.py`) carries
camera from/to keys (position, target, focal length mm, ease, orbit), focus rack (`focus.from/to/ap/rack`),
parameter tweens (`params`), overlay callouts and transition type. `scenes/engine.js` (`camFromShot`, `P()`)
evaluates them deterministically per frame, so any frame can be re-rendered in isolation.
